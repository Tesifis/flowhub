# Автоматический импорт расписания КФ МГТУ

На GitHub Pages нельзя напрямую прочитать `https://lks.bmstu.ru/lks-back/srv/v2/ics/...`: браузер блокирует запрос из-за отсутствующих CORS-заголовков. `worker/bmstu-relay.js` — небольшой публичный сервер для чтения только календарей МГТУ по UUID группы. Он не принимает произвольные адреса и не использует авторизацию.

## Публикация сервера

1. Создайте аккаунт Cloudflare, перейдите в **Workers & Pages** → **Create** → **Worker**.
2. Откройте редактор кода Worker, замените содержимое на текст файла [bmstu-relay.js](./bmstu-relay.js) и нажмите **Deploy**.
3. Проверьте адрес вида `https://<имя>.workers.dev/health`: он должен ответить `FlowHub BMSTU relay ready`.
4. В FlowHub откройте **Расписание** → **⋮** → **Импортировать расписание МГТУ** и вставьте опубликованный HTTPS-адрес в поле **Адрес сервера импорта**.
5. Вставьте адрес официальной страницы группы МГТУ, например `https://lks.bmstu.ru/schedule/bad34efb-ed29-11ef-becd-8753117d52b2`, нажмите **Загрузить по ссылке**, проверьте предпросмотр и подтвердите сохранение.

Важно: сейчас выбор группы осуществляется по ссылке официального расписания (UUID), а не только по её названию. Для поиска группы по номеру понадобится дополнительно установить и проверить API справочника групп МГТУ. Сервер Worker не развёртывается автоматически при публикации GitHub Pages.

## Проверка

- `/health` — диагностика сервера.
- `/ics/<uuid-группы>` — публичный календарь VCALENDAR.
- Используются только GET/OPTIONS и фиксированный домен МГТУ.
- Публичный результат кэшируется до 15 минут.
- Если МГТУ не отвечает, продолжайте использовать ручной импорт `.ics`.

Не указывайте в Worker токены, cookies или логин ЛКС. Используется только открытый календарь.

## Ограничения

Публичный сервер без авторизации может использоваться посторонними. Для активной эксплуатации стоит настроить лимиты запросов в Cloudflare, а также разрешить CORS только своему домену. Прямые запросы к МГТУ могут перестать работать при изменении API.
