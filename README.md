## О проекте

**FlowHub** — персональное пространство для организации учёбы и повседневных задач. Приложение ориентировано на телефон, но также открывается на компьютере. Интерфейс доступен в тёмной и светлой темах.

Проект развивается как веб-приложение (PWA). В планах — отдельная Android-сборка без полной переработки интерфейса.

## Возможности

| | |
|---|---|
| **Главный экран** | Дата, ближайшие занятия и обзор текущих дел. |
| **Задачи** | Создание, редактирование, выполнение, сроки и приоритеты. |
| **Заметки** | Быстрые записи и редактирование в едином интерфейсе. |
| **Расписание** | Ручное управление учебными парами. |
| **Привычки** | Прогресс по ежедневным целям и статистика. |
| **Персонализация** | Тёмная, светлая и системная темы. |
| **Хранение данных** | Локальная работа, JSON-резервная копия; необязательная синхронизация через Supabase. |
| **PWA** | Установка на главный экран и работа офлайн после первоначальной загрузки. |

## Попробовать

Откройте **[tesifis.github.io/flowhub](https://tesifis.github.io/flowhub/)** в браузере.

На Android можно добавить сайт на главный экран через меню браузера. Для офлайн-режима сначала откройте сайт с подключением к интернету. Отдельный APK пока не выпускается.

## Запуск локально

Для разработки не требуется сборщик или пакетный менеджер. Достаточно Python и любого современного браузера:

```bash
git clone https://github.com/Tesifis/flowhub.git
cd flowhub
python -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000). Вход и синхронизация с Supabase необязательны: без них приложение хранит данные локально.

## Синхронизация между устройствами

Для облачной синхронизации используется **Supabase**. Чтобы подключить собственный проект:

1. Создайте проект в Supabase и выполните `supabase.sql` в SQL Editor. Скрипт включает RLS для пользовательских записей.
2. Скопируйте **Project URL** и **publishable / anon key** из настроек проекта.
3. Укажите их в настройках FlowHub, зарегистрируйтесь или войдите в аккаунт.
4. Войдите с тем же аккаунтом на другом устройстве.

> [!IMPORTANT]
> Никогда не публикуйте пароли, `service_role` или секретные ключи в репозитории. Синхронизация находится в доработке: одновременные изменения на нескольких устройствах могут конфликтовать. Регулярно сохраняйте резервную копию важных данных.

## Технологии

**Frontend:** HTML, CSS, JavaScript без тяжёлых фреймворков.  
**PWA:** Web App Manifest и Service Worker.  
**Backend для синхронизации:** Supabase.  
**Публикация:** GitHub Pages.
