Напоминания

Напоминания работают, пока FlowHub открыт. Для уведомлений при закрытом приложении потребуется Web Push.

Настройки сохраняются на этом устройстве. Для фоновых push потребуется отдельная настройка сервера.

Синхронизация устройств

Без подключения FlowHub работает локально и офлайн. Для синхронизации нужен собственный проект Supabase; инструкция есть в README.

Не загружай конфиденциальные сведения в общедоступный репозиторий. Пароль хранится только в момент входа, не сохраняется приложением.
